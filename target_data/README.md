# Target Data Samples

This directory contains sample output data from the ETL processes for reference and validation purposes.

## Files

- `dim_customer_sample.csv` - Sample customer dimension records
- `dim_product_sample.csv` - Sample product dimension records
- `fact_sales_sample.csv` - Sample sales fact records

## Purpose

These files demonstrate:
1. Expected output format after ETL transformations
2. Surrogate key assignments
3. Calculated fields
4. SCD Type 2 implementation (customer dimension)
5. Data quality improvements (cleansing, standardization)

## Usage

Use these samples to:
- Validate ETL output
- Understand transformation logic
- Train new team members
- Compare expected vs actual results in testing

## Notes

- These are sample records only, not the complete dataset
- Dates and values are for demonstration purposes
- Actual production data will have different volumes and values
